1. **SHOULD-FIX — Apply adaptive rate changes to waiting acquisitions.** `crates/tidemark-fs/src/throttle.rs:67`, `:83`, `:204`. Reference: `04-scanner.md` §6.2, token bucket at the controller's rate; W1-D token-bucket details. `acquire` calculates its duration and reserves an immutable deadline using the rate at entry. The controller only updates the rate atomic, so already queued requests ignore subsequent decreases. An independent library-linked probe used max=100/s, min=1/s, interval=50 ms and consistently excessive latency. After explicitly spending the initial 25-token burst, 64 concurrent `acquire(1)` calls all completed within 641.5 ms, despite seven decreases and an ending rate of 1/s. The measured time-weighted rate implies only 10.3544 earned tokens during this period. A separate 1,000-unit acquisition at an initial 1,000/s finished after 750.3 ms although the rate had reached 1/s by 300 ms. This weakens the primary disk-load protection precisely when it detects overload. Account for outstanding token debt at each rate change and wake/recheck waiting acquisitions against that accounting. Add regression tests covering both concurrent unit-cost requests and bulk costs while the rate falls and recovers. Evidence: `library/throttle_unit_probe.rs`, `.log`, and `library/throttle_probe.rs`, `.log` in this attempt's output directory.

2. **SHOULD-FIX — Parse UID independently of unrelated non-UTF-8 status fields.** `crates/tidemark-fs/src/procfs.rs:144` and `:32`. Reference: `07-live-monitoring.md` §4.3 and the required adversarial procfs review. `read_uid` calls `text`, which strictly decodes the entire status file before finding its ASCII `Uid:` line. A valid Linux process comm of `b"bad-\xff-name"` produces `Name:\tbad-\xff-name` alongside a valid `Uid:\t0\t0\t0\t0`. The built library's `read_starttime` succeeds and `read_comm` returns its documented lossy string, but `read_uid` returns `InvalidData`. Consequently the attribution cache records `uid: None` for a readable identity. Parse the UID field from bounded byte lines, or use lossy decoding for this reader as the stat reader already does. Add a regression containing invalid UTF-8 outside the UID line. Evidence: `library/procfs_library_probe.rs` and `.log`; the earlier standalone-module probe also checked escaped systemd unit names, overflowing flags, and truncated stat input.

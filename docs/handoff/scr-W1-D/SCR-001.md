# SCR-001: Stable leaf identity and bounded sampler lifetime

- Raised by: W1-D    Date: 2026-10-11
- Affects: core::dev::DiskStat and throttle sampler contract    Docs: 04 §6.2, wave-1-primitives W1-D
- Affected tasks: W1-A, W1-D, W2-B

## Problem

DiskStat contains only counters, so controller_step cannot determine device identity or whether utilization is meaningful. BlockDevInfo has rotational status but no hardware queue count. A positional Vec from StatSampler silently compares unrelated counters if a sampler reorders devices. The synchronous FnMut callback can also block forever; no safe implementation can forcibly cancel it and still join the controller within one interval.

The gate constructor receives already-resolved leaves and an injected sampler; it has no root DevId with which to call resolve_leaves. Device discovery therefore needs to stay in the caller, with discovery errors converted to an empty leaf slice.

## Proposal

Keep the current types/signatures and state that callers resolve the root through blockdev::resolve_leaves(DevId), passing an empty leaf slice on unavailable discovery. Explicitly require StatSampler to return exactly one sample per leaf in the original leaves order, fail the whole sample on disappearance, and finish within AdaptiveParams.interval. Document controller_step as a counter-only function: callers mask io_ticks_ms to zero for devices where utilization must be ignored. Permit gate_from_config to inspect the bounded mq directory listing when constructing that mask. If arbitrary samplers or dynamic leaf sets are needed later, replace StatSampler with an identified, cancellation-aware sample contract through a separately coordinated change.

## Impact if accepted

W1-A read_disk_stats must preserve input order and return errors rather than dropping unreadable devices. W2-B must supply bounded kernel reads. No schema migration or Rust field-list change is needed.

## Interim

W1-D preserves the frozen signatures, documents stable order and bounded callback duration, checks sample counts, reads at most two mq entries, and masks utilization for nonrotational/unknown or multiqueue leaves. stop interrupts the wait and joins; tests cover a waiting controller and a released in-flight callback. Arbitrarily blocked callback shutdown is not claimed. No decision is inferred from this request.

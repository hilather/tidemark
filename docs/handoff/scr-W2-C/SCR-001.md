# SCR-001: Bulk lifecycle observability and recoverable phase-one failure

- Raised by: W2-C    Date: 2026-10-11
- Affects: bulk API and BulkStats    Docs: 04 §8–9; wave-2 W2-C sequence 7–10
- Affected tasks: W2-B, W2-C

## Problem
The frozen run_bulk signature consumes the Aggregator and returns only Prepared/BulkStats on success. Its current BulkError has NotYetImplemented and Cancelled, with no failure phase, recoverable partial aggregator, or progress callback. BulkStats omits the namespace walk's noatime_fallbacks. W2-C cannot safely distinguish a real pre-phase-two failure for automatic fallback, recover partial data on cancellation, report live counters/phases/ETA, or persist the namespace walk's noatime fallback count. Treating every failure as safe to retry would silently change the contract.

## Proposal
W2-B/coordinator should define a typed recoverable pre-phase-two error classification, a bounded progress observation seam, and cancellation ownership. One possible addition is BulkError::BeforePhase2(String), documented to mean no bulkstat phase-two acquisition has started; W2-C can create a fresh walk aggregator. Add noatime_fallbacks: u64 to BulkStats and either a callback argument to run_bulk or an observer carried in a separately agreed parameter. If --keep-partial must work for bulk cancellation, return an optional partial Prepared alongside a typed cancellation outcome. Exact signatures require coordinator agreement before implementation.

## Impact if accepted
W2-B propagates walker counters and emits progress; W2-C monitors the agreed seam, falls back only on the typed safe error, and persists partial output when available. No snapshot schema migration is needed.

## Interim
The orchestrator invokes the frozen signature and fails closed on bulk errors. Walk progress, walk cancellation and partial-walk publication are implemented. Bulk phase timings from successful BulkStats are persisted. Bulk live progress, automatic fallback, bulk keep-partial, and bulk namespace noatime counts remain gaps; no frozen fields/signatures were changed.

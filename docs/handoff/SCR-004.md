# SCR-004: Specify helper signatures and scan identifier suffix policy

- Raised by: W0-B1    Date: 2026-10-10
- Affects: path/time/units/dev/JSON core contracts    Docs: wave-0-foundation.md W0-B; 03-link-semantics.md §5; 08-interfaces.md
- Affected tasks: W0-B2 and all later core consumers

## Problem

Helper names and examples are given without Rust signatures, construction-error behavior, scan-id suffix policy or the Rust type of DevKind::Md.level. JsonDoc explicitly requires schema: &'static str, which limits borrowed serde deserialization to static-lifetime input.

## Proposal

Freeze the implemented signatures in core: RawName/RawPath::new(bytes: impl Into<Vec<u8>>) and from_path(&Path) return Result<Self, CoreError>; as_path returns &Path; join(&RawName) returns RawPath; parent/file_name return owned Options; starts_with takes &RawPath; display_lossy returns String; hash64 i64; to_json serde_json::Value. RawName also rejects dot/dot-dot and NUL; RawPath normalizes repeated slash, dot and dot-dot lexically, clamping above-root parents at root. Ordinary serde preserves byte arrays with validated deserialization. Display escapes controls, literal backslashes and invalid UTF-8 using uppercase byte escapes; valid printable Unicode is preserved. path_b64 uses padded standard base64.

ByteSize is a u64 newtype with checked decimal parsing, integers and binary-unit strings; decimal SI suffixes are also accepted. parse_rate returns Result<f64, CoreError>; fmt_rate accepts f64 and renders signed binary units/s, with 'unknown' for nonfinite inputs. Age boundaries are [i64; 5]. ScanId::new(now: i64) returns Self; the eight lowercase hex suffix hashes injected seconds, process id and a process-local atomic sequence without file I/O. This reduces collisions but is not cryptographic or a uniqueness guarantee; the snapshot writer must still avoid replacing an existing id. UTC seconds outside chrono's representable four-digit-year range use the epoch prefix rather than panic; the suffix still uses the original input. unix_now returns i64; duration helpers use Duration and CoreError. DevKind::Md.level is String (e.g. raid5); major/minor are u32; DiskStat fields u64.

Retain JsonDoc<T> { schema: &'static str, data: T } verbatim. Serialize is the ordinary output path. Its derived Deserialize requires 'de: 'static; readers needing owned arbitrary schemas should use their own owned envelope pending a separate approved change.

## Impact if accepted

No documented format changes. Callers handle fallible constructors and parsing. Store writers remain responsible for scan-id collisions. No regular-file reads or unsafe code are added. If suffix randomness or a different construction/error signature is required, settle it before core freeze.

## Interim

Implemented the above and boundary, round-trip, escaping, parsing and ID-format tests. Normative age equality uses the older bucket. Config::load is the sole file-I/O implementation; unix_now and process id are explicit OS information helpers.

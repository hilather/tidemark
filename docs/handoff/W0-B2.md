## What was built

Implemented the complete clap tree: 22 top-level commands, four snapshot operations, ncdu export, and three deployment operations. Command Args and error stubs live in their later owners' files; completions are implemented for every clap_complete shell. CLI and daemon executables are thin wrappers over libraries, with ordinary parent module declarations.

CLI support loads the existing core Config, merges built-in alert rules for a missing config, applies state-dir overrides, validates, configures stderr tracing, and supplies JSON/color policy to commands. CliError maps all six failure statuses; clap retains success for help/version and status 2 for usage errors. Shared render helpers use core JsonDoc, fmt_bytes and RawPath without redefining contracts. The daemon's check-config loads and validates the supplied file, reports every issue, and returns 2 for invalid configuration; normal startup remains the W6-A stub.

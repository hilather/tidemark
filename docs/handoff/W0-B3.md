## What was built

Added the W1-A–E, whole W4-A LVM, and selected W5-A/C/D public stub interfaces in the owning files. All 100 specified function signatures and 17 explicit field lists match the normative documents, including the existing core GateStats/VgInfo re-exports. Result functions fail explicitly, and the bulkstat iterator emits one Unsupported error then terminates; error-free signatures retain inert bodies as described in SCR-005. Added 20 tests that call every stubbed function across the five crates containing requested functions. Converted the scaffold's nested path declarations to ordinary private module declarations under their parent mod.rs files, including the scan crate.

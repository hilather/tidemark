# SCR-001: Preserve per-directory error totals independently of stored details

- Raised by: W2-A    Date: 2026-10-11
- Affects: core DirRecord / NsRecord fields    Docs: 03 §3, 04 §1, 05 §1
- Affected tasks: W1-B, W2-A, W2-B, W2-C

## Problem

`DirRecord.errors` and `NsRecord.errors` are the only error accounting inputs to the aggregator. W1-B's `worker::err` increments `Counts.errors` for every error but appends a detail only while the shared `MAX_ERRORS = 10_000` counter permits. Its `stored_errors_are_capped_but_totals_are_not` test demonstrates 10,017 errors with 10,000 details. `WalkSummary.errors` preserves the global count, but not its directory attribution. Once details are omitted, W2-A cannot reconstruct `DirRow.errors`, `t_errors`, or the root summary from records; substituting zero would violate the normative metrics. The bulk namespace stream has the same issue.

## Proposal

Add `pub errors_total: u32` to both `DirRecord` and `NsRecord`, defined as all errors attributed directly to that directory, independent of the length of `errors`. Check conversion at the producer. Populate it in W1-B, preserve it through W2-B, and use it for W2-A directory/error rollups. `errors` remains the bounded sample of detail rows. No snapshot schema change is needed. W2-C can cross-check the sum against `WalkSummary.errors`.

## Impact if accepted

Core contracts and all constructors/fixtures need the new fields. W1-B must track per-directory counts even when the shared detail cap is exhausted; W2-A must consume those counts. Add a regression with more than 10,000 errors across multiple directories and assert all directory totals independently of retained error details.

## Interim

Frozen public signatures/fields are unchanged. W2-A counts every error present in each input record before applying its own configurable detail cap. The missing upstream counts remain a known limitation; no attempt is made to attribute a global difference to an arbitrary directory.

## Decision (coordinator)

Pending. This request is evidence of a contract gap, not approval to change the contract.

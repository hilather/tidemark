## What was built

Implemented dispatch of exactly the twelve documented API method names using frozen core params/results and LiveState/ScanControl/reload interfaces. Authorization precedes version, method and parameter processing. Invalid input, unavailable measurements, busy scans, missing I/O objects and internal failures map to frozen wire codes. Alert history serves the bounded successfully persisted events from the current daemon run, documented in dispatcher rustdoc and alert help/footer.

Implemented injected-credential Unix transport with stale-socket inspection/removal, active-socket refusal, mode 0600, one connection worker per client, at most 32 admitted clients, bounded 1 MiB newline framing and response serialization, sequential calls, peer uid/pid logging, ten-second handler deadlines and prompt idle-client shutdown. A bounded additional handler worker per active request allows deadlines without pretending the frozen synchronous callback is cancellable. A stuck handler retains its admission permit until it exits; subsequent handlers cannot accumulate beyond the 32 permits. Detached timed-out callback threads may outlive the server handle; lifecycle process exit terminates them. Production startup remains disabled, as explained above.

Implemented daemon-backed now/hot/alerts/status commands via the existing Client. Connection failures use exit 4 and the requested service-status hint; permission failures also retain the shared sudo hint. Human now output uses the shared renderer at fallback width 100. JSON uses the existing command-schema envelope with the unmodified raw report as data. Hot, alerts and component health use aligned deterministic tables with shared byte escaping. Status also displays watcher modes, retained errors and scan next-run facts.

Added only daemon-first branches in the four shared commands. Scan starts, polls status, cancels on `--cancel` or SIGINT/SIGTERM, preserves frozen root adapters and rejects daemon-unsupported direct-only overrides rather than silently ignoring them. LVM renders frozen fields, reads trends read-only with the same query/slope/window as direct mode, omits absent segment/other-volume columns and prints the required notice. Writers and phantom honor explicit direct mode and fall back with one notice. Existing direct code in all four files is byte-for-byte retained.

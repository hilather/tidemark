## What was built

`gen_fixture.rs` streams deterministic report fixtures using SplitMix64 and Box–Muller, with unique-inode accounting, log-normal sizes, sparse large files, hard-link sets, file/directory symlinks and scaled wide directories. Root-component checks and no-follow directory fd capabilities through procfs anchor generation/cleanup/mutation; marker reads are bounded and no-follow. Marked-root regeneration validates the flat tree before deletion, refusing nested directories/mounts. Mutation uses fixed 25% create/append/link/delete logical operations, a 1024-slot bounded ring and optional duration.

`bench.rs` parses options and constructs commands as data. It runs du twice (allocated/apparent) and the release CLI with private config/socket/state, preserving printed results and collecting wall/CPU/RSS evidence. It streams baseline and scan leaf block stat series once per second. Cold-cache writes require explicit host-wide consent and effective root, with daemon/load refusals unless force. A separate root-only watcher experiment reports writer throughput loss with and without a private foreground watcher. No rustix feature or dependency was added: Linux directory/no-follow/no-atime flags use safe standard-library OpenOptionsExt and procfs fd paths. The developer sandbox has no GNU time, so the harness also offers a clearly labelled procfs CPU-tick/sampled-RSS fallback.

`docs/perf/README.md` provides operator commands, caveats, recording requirements, R4-8 watcher budget, all performance/soak gates and an empty results table.

## Assumptions and deviations

- Inode count means unique inodes, including root/directories/two control files. Hard-link aliases add entries only. Summary JSON is padded to 4096 bytes to include its own byte/block contribution without circular size arithmetic. Timestamps and filesystem-specific directory allocation are excluded from deterministic tree digests.
- Log-normal sigma is 2; three wide directories and at least five report directories scale down for small fixtures. At full scale regular report directories average about 35k originals, with hard-link entries increasing width.
- Existing marked roots are regenerated, including deleting their old flat fixture contents. They must contain no unrelated data. Unsupported nested directories fail before any deletion. No concurrent root rename/remount is supported; all ordinary file operations remain anchored through no-follow directory handles.
- Duration uses integer seconds; rates use logical operations/second. Every four operations cause two close-write events. Interrupts use normal process termination; interrupted work is cleaned on the next marked-root run.
- The current CLI JSON has counts/bytes/mode/errors but no gate statistics. These are reported unavailable rather than invented or added to a frozen contract. Du prints byte totals only; scanner JSON supplies directories/files. Syscall counts require external strace profiling.
- GNU time provides rusage maximum RSS; aggregate process-tree RSS is also sampled every 20ms. Brief peaks can be missed, and GNU time's maximum is not an instantaneous aggregate-tree peak. The procfs fallback is a sampled lower bound and CPU has clock-tick resolution. Use GNU time and cgroup memory evidence for staging gates.
- Block-device samples are independently taken from sysfs, not claimed to be the adaptive gate's exact internal sampling windows. Non-block-backed sandbox fixtures have no sysfs leaves and report an empty list.
- The watcher experiment includes foreground rendering overhead, checks liveness rather than definitive readiness, and reports mutation-only throughput separately from CPU/wall including fixture preparation. Verify event delivery and measure daemon watcher CPU separately against R4-8. High requested rates avoid masking writer slowdown. Preserve dense policy across trials.
- Temporary Cargo cache copied from the host cache; pinned toolchain binaries used directly because Cargo was absent from PATH and rustup's default home is read-only. All builds use offline mode. No host cache modification or package installation.

# SCR-001: Specify snapshot Rust types and query filters

- Raised by: W0-B1    Date: 2026-10-10
- Affects: core snapshot contracts    Docs: 05-storage.md §1, §3; wave-0-foundation.md W0-B
- Affected tasks: W0-B2, W1-D, W1-E, W2-A, W2-B, W2-C, W3-A, W3-B, W3-C

## Problem

The SQL defines columns and nullability, but not Rust integer widths or the fields of FileFilter and LinkFilter. W0-B requires FileHit to contain a full path while files.name is explicitly nullable after a bulk-mode race. Snapshot metadata phase_ms and gate_stats are JSON without a shape. GateStats is subsequently defined in tidemark-fs by W1-D, which core cannot depend on.

## Proposal

Freeze the interim definitions in crates/tidemark-core/src/snapshot.rs:

- Directory ids, depth, direct entry/error counts, link counts and project ids are u32; inode/device ids, sizes and subtree counters are u64; Unix seconds/path hashes are i64; errno is i32. SQL nullability maps to Option. files.id is u32 (bounded by max_notable). DirRow.name is Vec<u8> because the root stores a full path; other names are RawName. Paths are RawPath.
- SnapshotMeta includes all required keys in documented order. schema_version and threads are u32, count/size/device fields u64, timestamps i64, scan_id ScanId, root RawPath, mode ScanMode, status SnapshotStatus, degraded bool, exclude Vec<String>, link_instances LinkInstances; remaining scalar descriptive values are String (including fs_uuid, with empty string for unknown).
- phase_ms is BTreeMap<String, u64>. gate_stats is core::scan::GateStats, with the exact W1-D fields: mean_rate: f64, min_rate: f64, throttled_ms: u64, decreases: u64, increases: u64. W1-D should re-export this type rather than introduce an incompatible second type.
- FileFilter { min_size: Option<u64>, older_than: Option<Duration>, newer_than: Option<Duration> }; ages are relative to snapshot started_at. LinkFilter { incomplete: bool, boundary: Vec<String>, boundary_depth: Option<u32> }.
- FileHit { row: FileRow, path: Option<RawPath> }; None means the bulk race left no resolvable name. LinkSetHit { row: LinkSetRow, lca_path: RawPath, instance_count: u64 }; instance_count counts stored rows, while row.found retains the discovered count when link_instances=none.

## Impact if accepted

No SQL schema change. W1-E must enforce checked SQLite integer conversions and preserve missing names rather than fabricate paths. Later query/report tasks use the specified filter units and optional path. W0-B2/W1-D re-export core GateStats. Review these definitions before freezing core.

## Interim

Implemented this reading; no plan document or downstream crate was changed. A source audit confirmed every SQL column appears in order and every explicit scanner/live struct field matches its normative definition.
